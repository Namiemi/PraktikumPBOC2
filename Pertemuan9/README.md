# Konsep Koleksi dalam Pemrograman

## Pengertian Koleksi

Koleksi adalah sekumpulan objek atau data yang disimpan dalam satu wadah agar lebih mudah dikelola, diakses, dan diproses. Konsep koleksi digunakan ketika program membutuhkan penyimpanan banyak data dengan tipe yang sama maupun berbeda secara terstruktur.

---

## Cara Kerja Konsep Koleksi

Konsep koleksi bekerja dengan cara menyimpan banyak data ke dalam sebuah struktur khusus yang dapat melakukan berbagai operasi, seperti:

- Menambahkan data
- Menghapus data
- Mencari data
- Mengurutkan data
- Mengakses data tertentu

Setiap elemen di dalam koleksi biasanya memiliki posisi atau indeks tertentu, tergantung jenis koleksinya.

Contohnya:

- `List` digunakan untuk data yang berurutan.
- `Set` digunakan untuk menyimpan data unik tanpa duplikasi.
- `Map` digunakan untuk menyimpan pasangan key dan value.
